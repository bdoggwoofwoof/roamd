# Roamed

A free personal travel tracker (a rebuild of "Been"): mark countries as been / want to go / lived, plan trips by region → country → your own sections with reels, TikToks and photos, and compare maps with friends.

Plain static site, no build step. Deployed on Vercel (project `roamed`, https://roamed-amber.vercel.app).

Everything is saved on the device (localStorage + IndexedDB). Settings → Save backup makes a file with everything, photos included.

Map data: Natural Earth (public domain) via world-atlas; airports from OurAirports (public domain).
